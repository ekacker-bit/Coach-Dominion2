    Privacy and data control

    • Coach Dominion never asks for or stores your MyFitnessPal username or password.
    • The optional automated nutrition feed uses a revocable Coach Dominion key and transmits only daily calories, protein, carbohydrates, fat, date, timezone, and sample count.
    • Raw Apple Health records, food names, meal names, and diary notes are not retained by the automated feed.
    • Apple Health import reads only the export.xml file you deliberately choose. Unsupported health categories are ignored and never uploaded as raw XML.
    • Permission selections are stored per simulated account and grant no live provider access.
    • Remote storage is user-scoped when migration 009 is applied; otherwise state uses a clearly labeled user-scoped local fallback.
    • Disconnecting preserves account, sync, imported-record, and provenance history for auditability.
    • Deleting a connection here does not delete information from the original provider or remove records already copied into import history.
    • MyFitnessPal automation uses Apple Health and your own iPhone Shortcut; it is not a direct MyFitnessPal API connection. Demo sync remains visibly marked DEMO.
